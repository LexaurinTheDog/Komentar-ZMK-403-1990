# Komentář k zákonu č. 403/1990 Sb., o zmírnění následků některých majetkových křivd

Otevřený komentář k zákonu o zmírnění následků některých majetkových křivd — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; oprávněné osoby, vydání věci, dohoda o vydání, peněžní náhrady a oceňování staveb.

Konsolidované znění: dokument e-Sbírky `SB-1990-00403_2022-02-01`.
